# Library Inventory Management System

A Blazor Server web application for university students to browse, reserve, and manage library books, with administrative features for librarians.

## Technology Stack

- .NET 10
- Blazor Server
- Entity Framework Core (planned)
- MudBlazor (planned)
- SQL Server / PostgreSQL
